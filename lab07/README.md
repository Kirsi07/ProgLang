### Задание 1 **(2)**
*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*
```
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```
**Ответ:** Данный код характеризуется неопределенным поведением компилятора (unspecified behavior). Поскольку в стандарте C++ отсутствует фиксированное правило, определяющее очередность вычисления передаваемых в функцию аргументов, результат выполнения (13 или 15) будет напрямую зависеть от используемого компилятора и его настроек оптимизации.

```
int x=10, y=3;
x=15, y+=x, x+=y;
```
**Ответ:**  Инструкции будут выполнены строго поочередно слева направо, за что отвечает оператор «запятая». На первом шаге переменной x присваивается 15. На втором — к y прибавляется новое значение x, что делает y равным 18 (3 + 15). На финальном этапе x увеличивается на текущую величину y, в результате чего x становится равен 33 (15 + 18).
```
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```
**Ответ:** 1. Первым делом рассчитывается левая часть логического «И» (x > y++). Сравнение происходит со старым значением y (9), поэтому условие 10 > 9 истинно. Сразу после этого срабатывает постфиксный инкремент, увеличивая y до 10.
2. Так как левый операнд оказался истинным, вычисляется правая часть (y++ > 9). Здесь сравнение идет уже с актуальным значением y (10). Проверка 10 > 9 вновь дает истину, а значение y возрастает до 11.
3. Поскольку оба условия выполнены, отрабатывает тело оператора if и выводится строка yes, после чего программа печатает финальное состояние переменной y, то есть 11.

### Задание 5 **(2)**

*Программисты на Python для обмена значений двух переменных часто пишут строку*
```
a,b = b,a
```
*Проверьте, будет ли аналогичная строка на С++ (с точкой с запятой в конце) являться синтаксически
правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*
**Ответ:**
```
int a = 1, b = 2;
a, b = b, a;
```
1. Данная запись полностью корректна с точки зрения синтаксиса компилятора C++, однако она абсолютно не решает задачу обмена данных между переменными.
2. Вместо взаимообмена выражение из-за приоритетов операторов будет интерпретировано компилятором как последовательность: a, (b = b), a;.
3. Алгоритм вычисления выглядит так: сначала берется значение переменной a и игнорируется, затем выполняется операция b = b (переменная просто перезаписывает свое текущее значение), а в конце снова вычисляется и игнорируется a. По итогу обе переменные остаются при своих исходных данных.

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```
**Ответ:** 1. В коде используется каскад логических проверок «И» (&&), внутри которых скрыт «оператор стрелки» --> (совмещение постфиксного декремента x-- и сравнения с нулем > 0). Расчет идет по принципу ленивых вычислений (до первого несоответствия). Постфиксная форма уменьшает значение x на единицу сразу после того, как текущее условие было проверено.
Конечный результат определяется начальным значением x:
• При x >= 5: вся цепочка из 5 проверок возвращает истину, и декремент выполняется 5 раз. Результат равен x - 5.
• При 1 <= x <= 4: проверки прервутся в момент, когда актуальный x станет равен 0 (так как условие 0 > 0 ложно). Вычисления прекратятся, но декремент запущенного шага сработает. На выходе всегда получится -1.
• При x <= 0: первая же проверка сразу выдает ложь, дальнейшие шаги полностью игнорируются, а x успевает уменьшиться лишь один раз. Результат равен x - 1.
